說明
• 瀏覽器基於隱私，不會提供 MAC 位址。這裡顯示的 device.id 是瀏覽器為此網站產生的裝置識別碼，同一裝置在同一網站下通常固定不變。
• 若裝置有 Device Information 服務（0x180A），會一併讀取序號、型號、製造商等欄位。
• 網頁必須透過 HTTPS 開啟（例如 GitHub Pages）。
• 勾選「保持連線」會維持連線並即時顯示特徵值（R=可讀、W=可寫、N/I=通知），按「斷線」結束。
• 已讀過的裝置會保存在本機，重新整理後仍可看到；重新整理後需重新選擇裝置才能再連線。
